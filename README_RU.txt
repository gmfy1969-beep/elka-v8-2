ELKA v8.2 — полный проект с ремонтным отделом
====================================================
НАЧНИТЕ С Docs\05_Repair_Department_RU.pdf и Docs\01_Install_RU.pdf.

ИЗМЕНЕНИЯ
  РЕМ — ремонтный отдел, входит в общий остаток.
  45 — Передача в ремонт: ПР -> РЕМ.
  46 — Возврат из ремонта: РЕМ -> ПР, в том числе частичный.
  47 — служебный входящий остаток РЕМ, не обычная передача в ремонт.
  Адреса: РЕМ-01, РЕМ-02. Контроль количества и адресов сохранён.
  РЕМ исключён из доступного для комплектности: настройка ЦС|ПС|ПР.
  Просмотрщик получает ремонтные остатки и движения после публикации.
  Сверка с 1С поддерживает склад Ремонтный отдел; имя настройте под выгрузку.

КОМПЛЕКТ
  1_INSTALL_OPERATOR.cmd — новая рабочая книга, реальный справочник, ПУСТОЙ журнал.
  2_INSTALL_DEMO.cmd — учебная книга с маршрутом ремонта и просмотрщик.
  3_INSTALL_VIEWER.cmd — установка просмотра на компьютере пользователя.
  4_UPDATE_MACROS.cmd — обновление книги структуры v8.1/v8.2 с резервной копией.
  Setup\Workbooks — XLSX-основы (не содержат VBA).
  Setup\VBA_Operator, VBA_Viewer, Object_Code — макросы UTF-8 для установщика.
  Setup\Manual_Import_CP1251 — Windows-1251 + CRLF для ручного импорта VBA.
  Docs — подробные PDF и редактируемые DOCX.
  Tests — реальные протоколы этой сборки, проверки и исходники.
  Demo — примеры вложений, публикация, пример выгрузки 1С.

БЫСТРЫЙ СТАРТ
  1. Распакуйте архив ЦЕЛИКОМ в отдельную папку. Не запускайте из ZIP/7z.
  2. Windows 10/11 + настольный Microsoft Excel 2010+; русский язык программ
     без Unicode (кодовая страница 1251). Закройте Excel.
  3. Запустите 2_INSTALL_DEMO.cmd для обучения или 1_INSTALL_OPERATOR.cmd для работы.
  4. Установщик через Excel создаёт настоящую .xlsm, импортирует модули,
     устанавливает код событий, кнопки, меню и папки.
  5. Проверьте 45/46 на копии, сохранение/повторное открытие, вложения и просмотрщик.
  6. Работайте в новой установленной книге, не в шаблоне XLSX и не в демо.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
  Не переименовывайте XLSX в XLSM. Готовый бинарный VBA-проект собирается в Excel
  установщиком; в Linux его не подменяли файлом с неправильным расширением.
  Автотесты выполнены в LibreOffice (VBA compatibility) и Python, не в Windows Excel.
  COM-установка, PowerShell, окна выбора файлов, внешнее открытие документов,
  ярлыки и поведение сохранения в Excel требуют приёмки на вашем компьютере.
  Версия v6.1 не обновляется автоматически: создайте новую книгу и переносите
  данные отдельно с контролем остатков. Старая книга остаётся источником.
  Ремонт контролируется по артикулу/месту/адресу, не по отдельной ремонтной заявке.
  Для связи передачи и возврата используйте одинаковые заказ, партию и комментарий.
  Нельзя считать строки/места буквально безлимитными: Excel имеет предел строк;
  стандартный отчёт поддерживает до 12 учитываемых мест, источники списков конечны.
  Не меняйте маршрут уже использованной операции и коды исторической номенклатуры.
